# DevOps Портфоліо

Студентка прикладної математики. Маю досвід розробки мобільних та серверних застосунків, а зараз активно заглиблююсь в автоматизацію та інфраструктуру.

## 🎯 Професійна мета
Поєднати розробку (iOS) із сучасними інфраструктурними практиками: налаштуванням CI/CD, автотестуванням та ефективним керуванням серверами.

## 🛠 Технології

**Вже використовую:**
- **Код та Бази:** Swift, Java, R | MySQL, PostgreSQL, SQLite.
- **Інструменти:** Git, GitHub, Xcode, VS Code, JetBrains Rider.
- **QA & Адміністрування:** Postman, базовий Linux (Ubuntu), написання скриптів.

**Планую вивчити:**
- Docker та Docker Compose.
- CI/CD пайплайни (GitHub Actions, GitLab CI).
- Infrastructure as Code (Terraform) та хмарні провайдери (AWS/GCP).
